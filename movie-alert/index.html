Movie Alert

The second tickets open, you'll know.

GitHub Actions Telegram Bot API 🔒 Private repo

Why It Exists

A Telegram bot that watches BookMyShow for a specific movie, theatre, and date - and pings you the instant booking opens. No server to maintain: it runs entirely serverless on GitHub Actions, polling on a schedule and firing a Telegram alert the moment your combination goes live.

☁️

Serverless

Runs on GitHub Actions + cron - no server to host, patch, or pay for.

⚡

Instant Telegram Ping

Fires the moment your chosen movie/theatre/date opens for booking, not on a slow poll.

🎯

Configurable

Point it at the exact movie, theatre, and date that matter to you.
