🧩 Step 3: Manifest V3, Script World Isolation & Redirect Interception ▼

Script world isolation requires separating network interception ("world": "MAIN") from content script DOM operations ("world": "ISOLATED"):

{
  "manifest_version": 3,
  "name": "TUFHub - TakeUForward to GitHub Sync",
  "version": "1.0.0",
  "permissions": ["storage", "declarativeNetRequest"],
  "host_permissions": ["*://takeuforward.org/*", "*://api.github.com/*"],
  "background": { "service_worker": "scripts/background.js", "type": "module" },
  "content_scripts": [
    {
      "matches": ["https://takeuforward.org/plus/*"],
      "js": ["scripts/tuf/interceptor.js"],
      "run_at": "document_start",
      "world": "MAIN"
    },
    {
      "matches": ["https://takeuforward.org/plus/*"],
      "js": ["scripts/tuf/content.js"],
      "run_at": "document_idle"
    }
  ]
}

🔐 Step 4: Authentication Security & Tab-Based OAuth ▼ 

// background.js Tab Listener for Privacy Mode OAuth
chrome.tabs.onUpdated.addListener(async (tabId, changeInfo, tab) => {
  if (changeInfo.url && changeInfo.url.includes('.chromiumapp.org/?code=')) {
    const url = new URL(changeInfo.url);
    const code = url.searchParams.get('code');
    if (code) {
      const token = await exchangeCodeForToken(code);
      await chrome.storage.local.set({ token });
      chrome.tabs.remove(tabId);
    }
  }
});

// uploader.js Git 409 Conflict Retry Logic
if (res.status === 409) {
  const getRes = await fetch(url, { headers: { Authorization: `token ${token}` } });
  if (getRes.ok) {
    const getJson = await getRes.json();
    body.sha = getJson.sha;
    res = await fetch(url, { method: 'PUT', headers: { Authorization: `token ${token}` }, body: JSON.stringify(body) });
  }
}

from PIL import Image, ImageDraw, ImageFilter

def create_glowing_store_card(src_path, out_path, title_text):
    W, H = 1280, 800
    bg = Image.new("RGBA", (W, H), (11, 17, 32, 255))
    glow = Image.new("RGBA", (W, H), (0, 0, 0, 0))
    gdraw = ImageDraw.Draw(glow)
    gdraw.ellipse((800, -100, 1400, 500), fill=(249, 115, 22, 90))
    glow = glow.filter(ImageFilter.GaussianBlur(120))
    bg = Image.alpha_composite(bg, glow)
    bg.convert("RGB").save(out_path, quality=95)

✅ Step 10: 50-Point Master Checklist for Building ANY Extension ▼

Phase A: Ideation, Scope & Manifest V3 Core (Points 1-10)

  • 1. Define single-purpose extension scope to satisfy Chrome Web Store Policy.
  • 2. Specify manifest_version: 3 in root manifest.json.
  • 3. Minimize requested permissions (only ask for storage, declarativeNetRequest when needed).
