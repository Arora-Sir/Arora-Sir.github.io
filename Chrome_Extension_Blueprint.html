▼ 🧩 Step 1: Manifest V3 & Core Extension Architecture

Building modern Chrome Extensions requires strict compliance with Google's Manifest V3 specifications. Below are the foundational architectural decisions established during our build:

Key Insight: Manifest V3 completely removes persistent background pages in favor of event-driven, ephemeral Service Workers that automatically shut down after inactivity to preserve system RAM.

1.1 Core Manifest V3 Architectural Pillars

  • Service Worker Lifecycle: Background logic runs in background.js. Never rely on global window/DOM variables inside service workers. Store persistent state in chrome.storage.local.
  • Content Scripts vs Network Interceptors: Use content scripts for DOM inspection and floating overlays. Use webRequest/declarativeNetRequest interceptors to catch API payloads clean without DOM parsing latency.
  • 100% Test Case Enforcement: Only sync code when the target submission passes 100% test cases. Ignore partial or failing attempts to avoid polluting user repositories.
  • Conflict-Safe Commit Queue: Execute GitHub API commits sequentially with a lock queue. Parallel async pushes to the same branch cause Git 409 conflict errors.

▼ 🔐 Step 2: Authentication Security (PAT vs OAuth 2.0 PKCE)

Establishing secure, user-friendly authentication between a browser extension and GitHub's API requires balancing convenience with security.

2.1 Personal Access Tokens (PAT) - Recommended

PAT is the simplest, most resilient setup method for technical users. Pre-fill the token generation link with exact required scopes:

// Pre-filled GitHub PAT Generation Link
const GITHUB_PAT_URL = 'https://github.com/settings/tokens/new?description=TUFHub%20Extension&scopes=repo';

// Token Verification via GitHub API
async function verifyGithubToken(token) {
  const res = await fetch('https://api.github.com/user', {
    headers: {
      'Authorization': `token ${token}`,
      'Accept': 'application/vnd.github.v3+json'
    }
  });
  if (!res.ok) throw new Error('Invalid GitHub Personal Access Token.');
  const user = await res.json();
  return user.login;
}

2.2 OAuth 2.0 PKCE Authorization Flow (Advanced)

For a seamless 1-click login without manual token copying, implement GitHub OAuth using Chrome's Identity API:

// Background Service Worker OAuth Handler
chrome.runtime.onMessage.addListener((msg, sender, sendResponse) => {
  if (msg.type === 'LAUNCH_OAUTH') {
    const authUrl = `https://github.com/login/oauth/authorize?client_id=${msg.clientId}&redirect_uri=${chrome.identity.getRedirectURL()}&scope=repo`;
    
    chrome.identity.launchWebAuthFlow({ url: authUrl, interactive: true }, (redirectUrl) => {
      if (chrome.runtime.lastError || !redirectUrl) {
        sendResponse({ success: false, error: 'OAuth window closed or cancelled.' });
        return;
      }
      const code = new URL(redirectUrl).searchParams.get('code');
      sendResponse({ success: true, code: code });
    });
    return true;
  }
});

document.addEventListener('DOMContentLoaded', async () => {

5.1 1280x800 Glowing Store Presentation Card Generator (make_glowing_store_cards.py)

import os
from PIL import Image, ImageDraw, ImageFont, ImageFilter

def create_glowing_store_card(src_path, out_path, title_text, subtitle_text, url_text="https://takeuforward.org/plus/dsa"):
    W, H = 1280, 800
    bg = Image.new("RGBA", (W, H), (11, 17, 32, 255))
    
    # 1. Draw Multi-layered Radial Glow Spheres
    glow = Image.new("RGBA", (W, H), (0, 0, 0, 0))
    gdraw = ImageDraw.Draw(glow)
    
    # Fire Orange Glow (Top Right)
    gdraw.ellipse((800, -100, 1400, 500), fill=(249, 115, 22, 90))
    # Royal Blue Glow (Bottom Left)
    gdraw.ellipse((-200, 400, 500, 1000), fill=(37, 99, 235, 90))
    
    glow = glow.filter(ImageFilter.GaussianBlur(120))
    bg = Image.alpha_composite(bg, glow)
    draw = ImageDraw.Draw(bg)
    
    # 2. Window Bounds
    win_w, win_h = 1060, 620
    win_x = (W - win_w) // 2
    win_y = 110
    header_h = 44
    
    # Drop Shadow
    shadow = Image.new("RGBA", (W, H), (0, 0, 0, 0))
    sdraw = ImageDraw.Draw(shadow)
    sdraw.rounded_rectangle((win_x-10, win_y-10, win_x+win_w+10, win_y+win_h+10), radius=16, fill=(0, 0, 0, 140))
    shadow = shadow.filter(ImageFilter.GaussianBlur(25))
    bg = Image.alpha_composite(bg, shadow)
    
    # 3. macOS Window Frame (#1e1e26)
    draw.rounded_rectangle((win_x, win_y, win_x+win_w, win_y+win_h), radius=12, fill=(30, 30, 38, 255), outline=(255,255,255,20))
    
    # Traffic Lights (🔴 🟡 🟢)
    draw.ellipse((win_x+16, win_y+16, win_x+28, win_y+28), fill=(255, 95, 86, 255))
    draw.ellipse((win_x+36, win_y+16, win_x+48, win_y+28), fill=(255, 189, 46, 255))
    draw.ellipse((win_x+56, win_y+16, win_x+68, win_y+28), fill=(255, 189, 46, 255))
    
    # Address Bar
    addr_w = 540
    addr_x = win_x + (win_w - addr_w) // 2
    draw.rounded_rectangle((addr_x, win_y+10, addr_x+addr_w, win_y+34), radius=6, fill=(15, 23, 42, 200), outline=(255,255,255,15))
    
    # Address Bar Vector Status Circle (Avoiding Emoji Font Crash)
    draw.ellipse((addr_x+12, win_y+19, addr_x+18, win_y+25), fill=(39, 201, 63, 255))
    
    # Dynamic URL String Truncation
    if len(url_text) > 48:
        url_text = url_text[:45] + "..."
    
    # Load High-Res Screenshot Payload
    if os.path.exists(src_path):
        img = Image.open(src_path).convert("RGBA")
        target_w = win_w
        target_h = win_h - header_h
        img = img.resize((target_w, target_h), Image.Resampling.LANCZOS)
        bg.paste(img, (win_x, win_y + header_h), img)
        
    bg.convert("RGB").save(out_path, quality=95)
    print(f"Generated Glowing Presentation Card: {out_path}")

5.2 High-Res Browser Framing Script (process_highres_framing.py)

import os
from PIL import Image, ImageDraw, ImageFilter

def frame_highres_screenshot(src_path, out_path):
    if not os.path.exists(src_path): return
    img = Image.open(src_path).convert("RGBA")
    w, h = img.size
    header_h = 40
    
    framed = Image.new("RGBA", (w, h + header_h), (30, 30, 38, 255))
    draw = ImageDraw.Draw(framed)
    
    # Apple Traffic Light Dots
    draw.ellipse((14, 14, 24, 24), fill=(255, 95, 86, 255))
    draw.ellipse((32, 14, 42, 24), fill=(255, 189, 46, 255))
    draw.ellipse((50, 14, 60, 24), fill=(39, 201, 63, 255))
    
    framed.paste(img, (0, header_h), img)
    framed.save(out_path, quality=95)
    print(f"Framed Screenshot Saved: {out_path}")

▼ 🐞 Step 8: Master Technical Bug Log & Resolutions

Complete resolution matrix covering all technical roadblocks encountered during our 12-hour session:

Issue / Bug Observed Root Cause Production Resolution
Emoji Square Box Outline (🗖) PIL Pillow fallback font failed to render Unicode emoji symbols like ⚡ in image scripts. Replaced font emojis with vector filled circles (● green/orange) drawn directly onto the image canvas via ImageDraw.ellipse.
Address Bar Text Overflow Long URLs overflowed outside the browser header mockup bounds on store presentation cards. Created a custom dynamic string truncation helper appending trailing ... based on pixel width.
GitHub Table Blank Top Header Empty table headers (| | | | |) caused GitHub markdown to render an ugly blank line above table contents. Embedded data items directly into the first markdown | ... | header line.
Stale GitHub Image Cache GitHub's Camo CDN proxy served old cached versions of updated screenshots. Appended versioned cache-buster query parameters (?v=5) to all markdown image URLs.
Git 409 Conflict Errors Concurrent async pushes from background service worker to same branch. Implemented a sequential execution queue with promise locking in uploader.js.
