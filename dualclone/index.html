DualClone

Run two copies of any app on a Samsung phone, with no root.

Android Kotlin Shizuku GPL-3.0

Why It Exists

Samsung Dual Messenger and the Work Profile can run a second copy of an app, but the stock screens hide most apps. DualClone uses Shizuku to clone any installed app into Dual Messenger or a Work Profile, keeps the list in sync, and stays fully offline except for the optional GitHub update check.

📱

Any App, Two Copies

Clone into Dual Messenger or a Work Profile, and remove the clone without touching the original.

🔓

Shizuku, No Root

Runs package commands through Shizuku over wireless debugging. No root and no accessibility service.

🎨

Material You Themes

Blue, Orange, Teal, Purple, wallpaper colors and a custom picker, plus a Pure AMOLED black with a ten step surface lift.

🔄

Signed Updates

Verified GitHub releases through the in-app updater, Obtainium or ObtainX. No trackers.
