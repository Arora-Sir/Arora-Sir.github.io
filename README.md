## 🛠️ Apps & Side Projects

Real, active tools sourced straight from my GitHub - not placeholders:

- **[TUFHub](https://tufhub.mohitarora.me)** - Chrome extension that auto-syncs accepted TakeUForward (TUF+) solutions to GitHub in real time. Also on the [Chrome Web Store](https://chromewebstore.google.com/detail/tufhub/fbbjinonammckffpfmhicgdcfgodfnge).
- **[DarQ Reborn](https://github.com/Arora-Sir/DarQ-Reborn)** - Per-app Force Dark theming for Android 10+ via Shizuku or root, with an Xposed/LSPosed module. Actively maintained, 83+ stars.
- **[Gravity Bridge](https://github.com/Arora-Sir/Gravity-Bridge)** - Control a local AI coding agent (Antigravity 2.0) from your phone's browser, with wireless file transfer. 13+ stars.
- **[CopyClip](https://github.com/Arora-Sir/CopyClip)** - Real-time clipboard sync across a laptop and phones over Tailscale/ADB. No cloud, no account. My most actively developed project right now.
- **[Chatalytics Pro](https://arora-sir.github.io/chatalytics-pro)** - Privacy-first WhatsApp chat analyzer, everything client-side. [Live demo](https://arora-sir.github.io/chatalytics-pro).
- **[Movie Alert](https://github.com/Arora-Sir/Movie-Alert)** - Telegram bot that pings you the instant a movie opens for booking on BookMyShow. Runs serverless on GitHub Actions.
